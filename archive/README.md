# Original project archive

`original-project/` preserves the supplied Desktop project folder and its five version folders. The active code at the repository root comes from `5th version/cricket-ball-tracker (1).zip`.

Earlier versions, ZIP bundles, source footage, study CSVs, previews and generated outputs are preserved here for traceability. Python bytecode and pytest caches are omitted. Duplicate media and ZIPs are retained to preserve the supplied records. These historical files are not the active source tree.

`manifest.json` records each preserved file's relative path, byte size and SHA-256 hash. Original files on the Desktop were left untouched.

The fifth version is the latest available exported source. The historical handoff warns that a previous Linux working directory may have contained later changes; that directory is not part of this Windows copy.
